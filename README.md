# Video Game Sales Analysis

## 1. Introduction
This project focuses on analyzing video game sales data using Python. The main purpose is to understand video game sales across different platforms, genres, publishers, and regions. Through data analysis and visualization, I aim to identify sales trends and gain useful insights from the dataset.

## 2. Objectives
- To explore and understand the video game sales dataset.
- To identify the best-selling video games, platforms, and genres.
- To analyze sales across different regions.
- To examine sales trends using charts and graphs.
- To practice Python programming and data analysis skills.

## 3. Dataset
The project uses the `videogamesSales.xlsx` dataset and the cleaned dataset, `videogamesSales_cleaned.xlsx`.

The dataset contains information about video games, including their names, platforms, release years, genres, publishers, and regional sales.

## 4. Tools and Libraries
The project uses Python and the following libraries:
- **Pandas:** For loading, cleaning, and analyzing data.
- **NumPy:** For numerical operations.
- **Matplotlib:** For creating charts and visualizations.
- **Seaborn:** For creating statistical visualizations.
- **Jupyter Notebook:** For writing and running Python code.

## 5. Data Cleaning
The dataset was examined and cleaned to prepare it for analysis. The process involved checking the data structure, identifying missing values and duplicate records, and preparing the data for further analysis.

## 6. Exploratory Data Analysis
Exploratory Data Analysis (EDA) was performed to understand the dataset and discover patterns in video game sales. The analysis explored sales by platform, genre, publisher, and region, where supported by the available data.

## 7. Data Visualization
Charts and graphs were created to present the analysis results clearly and make sales patterns easier to understand.

## 8. Project Files
- `project.ipynb` — Jupyter Notebook containing the Python code and analysis.
- `videogamesSales.xlsx` — Original dataset.
- `videogamesSales_cleaned.xlsx` — Cleaned dataset.

## 9. Conclusion
This project provides practical experience in using Python for data analysis. It helps develop skills in data cleaning, data exploration, and visualization while improving understanding of video game sales data.

## 10. How to Run the Project
1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries: `pandas`, `numpy`, `matplotlib`, and `seaborn`.
4. Open `project.ipynb` in Jupyter Notebook.
5. Run the notebook cells in order.
